# 实验说明（README_experiments.md）

## 1. 怎么做实验

```powershell
python -m ml.train
```

这条命令会训练 3 个模型，把每一次都记进 MLflow，最后自动挑误差最小的那个写进 `models/model.pkl`。

看实验记录：

```powershell
python -m mlflow ui
```

打开 <http://127.0.0.1:5000>，进入 `car-price` 实验，能看到 3 次运行，可以打勾对比。

## 2. 三个实验的差别

| 实验名 | 模型 | 输入特征 | 一句话说明 |
| --- | --- | --- | --- |
| `linear` | 线性回归 | 年份、里程、排量 | 最朴素的基线，只会画一条直线 |
| `linear_age2` | 线性回归 | **车龄、里程、排量、车龄²** | 换了特征，直线就能“弯”起来 |
| `forest` | 随机森林（30 棵树，深 6 层） | 年份、里程、排量 | 很多棵决策树投票，能学非线性关系 |

**关键点：`linear` 和 `linear_age2` 是同一个算法，只是一个换了特征。**
这正好说明：**把特征做对，比换一个更复杂的模型更有效。**

## 3. 结果

在 v2 数据（136 行，按 8:2 分成 108 行训练 / 28 行测试）上：

| 实验 | MAE（平均误差） | R²（解释度） | 结论 |
| --- | --- | --- | --- |
| `linear` | 1299 | 0.961 | 基线 |
| **`linear_age2`** | **551** | **0.9933** | **最好，上线** |
| `forest` | 1566 | 0.926 | 比基线还差 |

### 这两个指标是什么意思

- **MAE**：平均每次估错多少钱。551 就是“平均猜错 551 欧元”，越小越好。
- **R²**：模型能解释多少价格差异，1.0 是完美，0 是乱猜。0.9933 表示能解释 99.33% 的波动。

### 为什么随机森林反而更差

因为这份数据的关系很“平滑”（价格随车龄平滑下降），而随机森林擅长的是**有跳跃、有分段的复杂关系**。数据量又只有 108 行训练数据，随机森林容易在小数据上“背答案”（过拟合）。所以它输给了“把特征做对”的线性回归。

这个结论本身就是个加分点：**不是模型越复杂越好，要看数据长什么样。**

### 为什么加“车龄平方”就变好了

车价不是在直线下跌：前 3 年掉得最快，10 年以后掉得很慢。这是曲线关系。

原来的输入是“年份”（2020、2015……），模型只能算出 `价格 = a×年份 + b`，是一条直线。
换成“车龄”（6、11……）再加一个“车龄的平方”（36、121……），模型就能算出：

```text
价格 = a×车龄 + b×车龄² + c×里程 + d×排量 + e
```

因为带平方，这条线可以弯，于是更贴近真实规律，误差从 1299 掉到 551。

## 4. 每次运行都记录了哪些东西

| 类型 | 记了什么 | 为什么 |
| --- | --- | --- |
| 参数 | `model`、`feature_set`、`train_rows`、`test_rows` | 知道这次是怎么跑的 |
| 参数 | `dataset_hash` | **用的是哪一版数据**（对应 DVC 的版本） |
| 参数 | `git_commit` | **用的是哪一版代码** |
| 参数 | `test_size`、`random_state` | 切分比例和随机种子，复现实验要用 |
| 参数 | `n_estimators`、`max_depth` | 森林自己的超参数（只记在 `forest` 那次运行上） |
| 指标 | `mae`、`r2` | 比较模型好坏 |
| 文件 | `linear.pkl` / `linear_age2.pkl` / `forest.pkl` | 训练出来的模型本身 |

有了 `dataset_hash` + `git_commit` + 超参数，任何一个模型都能**原样重跑出来**。

## 5. 怎么判断该让哪个模型上线

看代码里的这一行（`ml/train.py`）：

```python
best_name = min(results, key=lambda name: results[name]["mae"])
```

谁的 MAE 小谁上线。本次结果是 `linear_age2`。

上线的模型会写进：

- `models/model.pkl` —— 网站直接加载这个文件；
- `models/metrics.json` —— 网站页脚显示指标、测试也会读它；
- `ml/registry/current_model.md` —— 人看的“当前线上模型是谁”。

## 6. 怎么再加一个实验

1. 在 `ml/configs/params.yaml` 改参数（比如 `n_estimators` 从 30 改成 100）；
2. 或者改 `ml/data_pipeline.py` 里的 `make_xy_with_features` 加新特征；
3. 重新跑 `python -m ml.train`；
4. 去 `mlflow ui` 里对比新旧两次运行。

代码不用大改，这就是参数化和实验追踪的意义。
